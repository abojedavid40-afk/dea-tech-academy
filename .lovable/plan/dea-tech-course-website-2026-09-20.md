# DEA TECH Course Website

## Overview
Build a polished, responsive tech-learning website for DEA TECH using a navy and electric-blue visual system. The first page will immediately showcase the brand, available skills, course pricing, and clear enrollment actions.

## What will be built
- Branded navigation with course links and a prominent enrollment action
- Immersive first section introducing DEA TECH and its learning promise
- Four photo-led course cards:
  - Software Development — ₦50,000
  - Data Analysis — ₦40,000
  - Cybersecurity — ₦45,000
  - Graphic Design — ₦20,000
- Course filtering and detail interactions so visitors can compare paths
- Learning benefits, practical curriculum highlights, and student outcome statistics
- Clear enrollment section and polished footer
- Mobile navigation and layouts optimized for phones, tablets, and desktops

## Visual direction
- Deep navy background with brighter royal/electric-blue accents
- Editorial, high-contrast typography with a modern technical feel
- Realistic technology-learning photography for every course
- Restrained glass-like surfaces, fine borders, and subtle motion
- Semantic design tokens for consistent colors, spacing, and states

## Technical details
- Implemented in the existing TanStack Start app at the home page
- Reusable React sections and course data structure
- Accessible controls, visible focus states, and reduced-motion support
- Unique page metadata for search and social sharing
- Final browser checks at desktop and mobile sizes
